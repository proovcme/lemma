# Границы публичной версии

Публикуется самостоятельное приложение с миграциями и вымышленным демонстрационным набором. Производственные базы, сотрудники, проекты, модели, вложения, журналы, ключи, конфигурация серверов и внутренняя Git-история не включаются.

Рабочая установка создаёт одного администратора и пустой реестр проектов. SQLite-демо проверяется отдельным аудитом: все адреса зарезервированы для примеров, имена и проекты вымышлены, контакты, вложения и версии моделей отсутствуют.

Внешние служебные каналы обновления и уведомлений не требуются. Revit отключён, его API закрыт в Caddy. Настройки SMTP принадлежат владельцу установки. Сборка не устанавливает телеметрию и не регистрирует автоматическую отправку почты.

Бизнес-ядро происходит из зафиксированного коммита в `manifest/release.json`. Локальные адаптации: публичное название и примеры, самостоятельная установка, границы демо и исключение непоставляемых приложений. При обновлении ядра эти отличия проверяются заново, а не перекрываются копированием всего внутреннего репозитория.
