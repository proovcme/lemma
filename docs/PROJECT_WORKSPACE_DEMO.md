# Проект: публичный прототип от 25.10.2026

В режиме `DEMO_MODE=1` обычная карточка `/projects/{id}` открывает новый компактный интерфейс. `?classic=1` возвращает прежнюю карточку; режим редактирования `?edit=1` продолжает работать как раньше. Рабочая установка с выключенным демо сохраняет прежний интерфейс.

Сводка и работы используют доступные текущему пользователю задачи Леммы. Материалы показывают существующий реестр исходных данных; сверка файловой шары пока не подключена. Команда, план, задачи, личное время, поиск и создание задачи ведут в действующие разделы приложения. Финансовые данные не включаются в JSON нового экрана.

Показатели — отдельный эксперимент в браузере: ручной ввод с основанием либо явная привязка к XLSX/листу/ячейке. Найденное значение требует подтверждения. Новая редакция источника сохраняет ранее принятое значение, пока человек не примет новое. Сохраняются адрес, хеш, автор решения и ограниченная история. Значения, привязки и метаданные источника хранятся только в localStorage этого браузера отдельно для каждого проекта; файл и полные листы не сохраняются и на сервер не отправляются. Переключение демо-роли использует тот же локальный набор показателей. Это не серверный реестр и не проверка авторизации для записи в рабочую базу.

Чтение ограничено XLSX до 5 МБ, 20 листами и 20000 ячейками. XML-сущности, шифрованные архивы, неподдерживаемое сжатие и превышение лимитов отклоняются. Формулы и макросы не исполняются; сохранённый результат формулы помечается. Пустое значение не превращается в ноль. Две вымышленные таблицы для проверки лежат рядом с кодом интерфейса в `public/assets/project-workspace/examples`.

Проверено локально: PHP lint, синтаксис JavaScript, 192 теста ядра / 974 проверки, вход директора и переход в проект, импорт XLSX и подтверждение ячейки, мобильная ширина 390 px без переполнения. HTTP-проверки локально и публично: вход обязателен; директор видит 42 задачи, инженер — 3 и не получает право редактирования; неизвестный проект даёт 404; прежняя карточка и четыре новых статических ресурса доступны.

Публично в браузере проверены вход, новая сводка, XLSX 12480 → подтверждение → редакция 12820 с сохранением принятого 12480, сохранение после перезагрузки и мобильный экран. Ошибок и предупреждений консоли в этом прогоне не обнаружено. Остальная Лемма сохраняет прежние экраны. Работа с реальной сетевой шарой, общая серверная запись показателей и полноценная проверка XLSX-совместимости остаются следующими этапами.

Изменение публикуется как ограниченный пакет поверх подтверждённой сборки публичного демо, без замены внутреннего приложения и без миграций БД. Предыдущая сборка сохраняется для отката. Изменения standalone-поставки не объявляются отдельным стабильным выпуском только на основании этой проверки демо.
