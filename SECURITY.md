# Безопасность

Сообщайте о потенциальных уязвимостях через приватный GitHub security advisory этого репозитория или на hello@locia.work. Не прикладывайте реальные пароли, ключи и рабочие базы.

Наружу доступен только Caddy; MariaDB и PHP-FPM не публикуют порты хоста. Используйте HTTPS, резервные копии вне сервера и актуальные базовые образы. `.env` и резервные копии содержат секреты. Ролевой демо-вход не используется в production-режиме.

Проверки CI уменьшают риск регрессий, но не являются независимым аудитом безопасности.
